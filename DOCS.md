# NEXUS Personal Agent OS — Developer & Production Architecture Guide

NEXUS is an open-source, production-grade **Personal Agent Operating System** built with a 5-agent LangGraph supervisor swarm, Sarvam Indic AI voice pipeline, accountable autonomy consent ledger, PostgreSQL database persistence, and HTML5 live webcam vision AI.

## 🔑 Environment Variables Configuration

Copy `.env.example` to `.env` and configure your API keys:

```env
# General
PROJECT_NAME="Personal Agent OS - NEXUS"
ENVIRONMENT="development"

# PostgreSQL Database
POSTGRES_USER=postgres
POSTGRES_PASSWORD=postgres
POSTGRES_DB=personal_agent_os
POSTGRES_HOST=db
POSTGRES_PORT=5432
DATABASE_URL=postgresql://postgres:postgres@db:5432/personal_agent_os

# Redis Cache
REDIS_HOST=redis
REDIS_PORT=6379
REDIS_URL=redis://redis:6379/0

# Sarvam AI (Indic Voice Pipeline)
SARVAM_API_KEY=your_sarvam_api_key_here
SARVAM_BASE_URL=https://api.sarvam.ai

# OpenAI (GPT-4o-mini Intent Classification)
OPENAI_API_KEY=your_openai_api_key_here

# Frontend & CORS
BACKEND_CORS_ORIGINS=["http://localhost:3000","http://127.0.0.1:3000"]
NEXT_PUBLIC_API_URL=http://localhost:8000
NEXT_PUBLIC_WS_URL=ws://localhost:8000
```

## 📡 API Endpoints Overview

| Endpoint | Method | Description |
|---|---|---|
| `/api/v1/agent/query` | `POST` | Dispatches user query through LangGraph supervisor swarm |
| `/api/v1/consent/ledger` | `GET` | Lists all consent ledger entries (append-only) |
| `/api/v1/consent/approve/{id}` | `POST` | Approves and executes a gated agent action |
| `/api/v1/consent/reject/{id}` | `POST` | Rejects a pending gated action |
| `/api/v1/voice/transcribe` | `POST` | Sarvam Saarika v2 ASR (speech-to-text in Hindi/Telugu/Tamil) |
| `/api/v1/voice/synthesize` | `POST` | Sarvam Bulbul v2 TTS (text-to-speech with natural Indian accent) |
| `/api/v1/vision/analyze` | `POST` | Analyzes webcam image frames for facial emotion and focus metrics |
| `/api/v1/brief` | `GET` | Fetches daily Morning Intelligence Brief generated by background cron |
| `/ws/agent-stream` | `WebSocket` | Real-time LangGraph node trace streaming for live node graph UI |

## 🧪 Testing & Quality Assurance

Run complete backend test suite (`23 test cases`):

```bash
cd backend
python -m pytest tests/ -v
```

Build Next.js production bundle:

```bash
cd apps/web
npm run build
```

---

## 🐳 Docker Production Deployment

To start the full stack (PostgreSQL, Redis, FastAPI Backend, Next.js Frontend) in Docker:

```bash
docker compose up -d --build
```

Access services:
- **NEXUS Mission Control**: http://localhost:3000
- **FastAPI OpenAPI Swagger**: http://localhost:8000/docs
- **Health Check**: http://localhost:8000/api/v1/health
